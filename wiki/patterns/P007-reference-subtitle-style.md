# P007 · 正文字幕用“中部单行锚点”，标题卡另做层级

**状态**：active ｜ **首次记录**：2026-10-08 ｜ **来源**：两条本地竖屏参考片抽帧观察，原始观测见 `raw/R20261008-subtitle-reference-review.json`

## 观察到的样式

两个参考样本都采用正文卖点字幕，而非常见底部双行听写字幕：

- 一行、水平居中，字块中心大约在画面高度 `0.614–0.623H`。
- 主文字为白色，粗黑描边，无实色底框。
- 少数关键词（数字、空间名、关系词等）标黄色，其余保持白字。
- 字幕压缩口播成为一眼可扫的事实锚点，不逐字复制配音。
- 标题卡可用两行层级，与正文字幕样式分开。

公开仓库只记录这些视觉规律与 SHA 级来源索引，不保存视频或真实帧；示例 PNG 是抽象重绘。

## 解读与改进

这种设计让字幕更像画面内的“重点标注”，不形成底部广告条；黄色负责第一视觉落点。若把整句做成字幕，或全部文字都标黄，就失去这套样式的层次。

## 新片应用规则

1. 默认将字块中心放在 `0.61H` 左右，试制容差 `0.59–0.63H`；必须结合实际主体、平台 UI 和目标手机抽帧验证。
2. 正文单行，字高初始设为 `4.0–4.8%H`，左右安全边距各至少 `5%W`。超宽先改短文案，不能自动缩成难读小字或自动换行。
3. 每行只标黄 1–2 个可回指事实来源的锚点。黄色不提升证据等级。
4. 字幕在事实层面压缩旁白；不新增数字、房间归属、朝向或实时房况。旁白也不能从字幕未核证地扩写新主张。
5. 标题卡、户型信息卡另立版式，不套用正文规则。
6. 经用户批准的不同风格可以覆盖默认值，但应先写入脚本合同并与本模式的参考观察区分。

## 失败模式

- 将正文字幕固定贴在画面底部，忽略参考片的中部定位与安全区。
- 加不透明黑底条，遮挡室内关系或产生广告横幅感。
- 整句全黄，失去信息层级。
- 逐字复写口播，造成字多、行长和视觉噪声。
- 根据版式推断字幕里的事实真实；样式正确不证明内容正确。
