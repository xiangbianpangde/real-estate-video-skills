# BGM开头素材库

原曲不动；来源、区间、参数、文件SHA、实际时长及响度见清单.json。

- 音频目录：WAV为48kHz/24-bit立体声剪辑母版，M4A为AAC试听版。
- 默认取原曲0–35秒；短于35秒的来源只取实际全长，不循环或补静音。
- 入点20ms、末尾0.8秒淡化，响度目标−18 LUFS、真峰目标−2 dBFS；实际值见清单。
- 25–35秒房产视频可直接导入母版，按成片长度裁短并重新淡出；旁白处另作音量让位，不能将素材库响度当作最终混音音量。
- 浏览器打开试听索引.html；来源含人声时需核听是否与旁白冲突。本工具不鉴定授权或曲目版本，不更改原文件。

本批5首；天真的橡皮为DJ阿狸版，并非此前的DJ小辞版；未提供黑神话悟空国潮。本批按实际来源分别整理，不将这些差异视为已授权版本替换。

完整原曲统一存放于 ../原曲，SHA未变；35秒片段不是时长上限。40秒或更长版本请从原曲重新裁剪，不重复编码或拼接短片段。清单source为当前原曲位置；processing_source_path和处理命令保留实际历史路径。
