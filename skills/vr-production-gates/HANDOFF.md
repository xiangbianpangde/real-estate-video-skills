## 2. 已固化的规则

| 主题 | 结论 | 权威落点 |
|---|---|---|
| 字幕覆盖 | `verbatim_voiceover` 完整口播与 `editorial_keywords` 卖点压缩是独立模式；不得从视觉样式推断覆盖范围 | subtitle-style 内容与交付模式 |
| 交付方式 | 烧录与可开关轨独立约定；完整口播直接上屏采用 `verbatim_voiceover + burned_in` | subtitle-style 内容与交付模式 |
| 参考样式 | 正文单行居中、约0.61H、粗黑体白字/少量黄标、粗黑描边、无底框；值为起始模板，必须目视验证 | subtitle-style 可执行参数 |
| 首尾区别 | 开场标题卡、正文、尾镜分别核验；正文参数不套资料卡；只验正文不能声称整片与示例一致 | SKILL 字幕参考对齐门 |
| 资料卡双层 | 事实标题与完整口播分层，可上下排布；标题不能替代口播，主体区域按素材实测，不照搬案例坐标 | subtitle-style 资料卡双层排版 |
| 行首标点 | 拆行/连续cue不得以逗号等结束性标点开头，标点留在上一行；不删口播文字 | subtitle-style 资料卡双层排版 |
| 事实与许可 | 新事实按项目合同另存登记；登记≠上屏许可。冻结档案不改；CTA默认空，另行授权 | SKILL 对齐门5 |
| 参考差异 | 白底资料卡与示例室内背景/留言CTA结构不同，manifest与审看入口明写差异，不复制参考事实/CTA | subtitle-style 修订范围 |
| 时间同步 | 按最终成片口播落点排时，不直接用TTS局部SRT；尾音不可为固定片长静默裁掉 | SKILL B9 |
| 锚点回归 | 每cue写中心/顶边锚点、坐标系、含描边包围盒；未改cue与基准几何核对，不只判安全带 | subtitle-style 锚点与未改区域回归 |

| 阻塞处置 | 脚本缺陷引发越权也判不合规，保留阻塞证据，不作交付候选；修正预检后仍等新take许可 | SKILL 对齐门6 |

### 回归经验与撤回记录

1. SRT逐字一致不证明编码画面无丢字；需分色排版预检、每字符实帧核验、几何和颜色检查。墨迹宽守卫依赖字体bearing/空格，只是启发式；连通簇数也不能代表字数。
2. 正文对比须明确源SHA、PTS、帧集合、字幕排除和ROI。早期534/444帧统计已撤回，正确无字幕集合为502帧（包含全部正文镜头）。案例噪声阈值不是通用质量保证，也不替代字形检查。
3. 8位灰度差上限255，旧“≤1000”阈值无效，已撤回；只报告实际变量和可失败的约定门。重编码像素不同本身不证明内容变化，旧比特恒等阻塞结论作为历史诊断保留。
4. 音频检查必须散列真实流，不能散列ffmpeg null输出空缓冲。旧take07检查无效已登记，不追认；真实流一致不替代音轨实听，ASR也不等于实听。
5. 报告历史与当前门状态必须自洽：旧阻塞判据标记被替代；音频字段指向实际候选；技术、结构、覆盖与人审分开，不用“全通过”掩盖开放项。
