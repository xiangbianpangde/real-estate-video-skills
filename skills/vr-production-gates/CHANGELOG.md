# Changelog

## 2.6.0 - 2026-10-10

- 新建文案部分及《文案中不能出现的内容》，首项为公摊：只用于内部面积计算解释，禁止进入视频可见/可听内容，包括同义表达与素材内嵌文字。
- 面积核验区分建筑、套内建筑、使用及房间面积，不猜公摊比例、不用公摊未经核证消解户型图差异。
- 接入脚本审阅、两种执行模式和成片禁用审查；已批准完整口播冲突回审，不自动删字幕、改音轨或生成视频。

## 2.5.0 - 2026-10-10

- 首尾优化新增目标截图优先级及 `reference_match` / `approved_variant`，不再把资料卡兼容排版当作参考结构达标。
- 新增首尾结构协议：室内背景、两行大标题、半透明圆角户型浮层；室内尾镜单行 CTA。提供归一化人工测量起点，非精确复刻保证。
- 要求源时间区间、浮层进出帧、含描边包围盒、新结构主体重测及正文/音轨回归；首/尾/技术/口播/人审分开判定。
- 完整口播/免责声明与目标冲突先审台本，不自动删句；仅优化 Skill 不允许渲染新 take。

## 2.4.0 - 2026-10-08

- 基于真实资料卡预览与阻塞案例，补充事实标题/完整口播双层排版、主体区域守卫、行首标点、事实版本登记和上屏授权分离。
- 补充中心/顶边锚点及基准包围盒预检；重编码差分改用逐帧PSNR并标注案例阈值非通用标准，差异大不代表正确。
- 越权产出立即阻塞保留证据，修正后仍需新授权；补充复制参考CTA的拒绝执行触发场景。

## 2.3.0 - 2026-10-08

- 增加字幕参考对齐门：直接读参考视频，首镜标题卡、正文、尾镜分别核验，禁止仅验正文便声称整片一致。
- 明确首镜背景/标题/户型图三层与尾镜背景/收束/CTA边界；新增背景、事实标题或 CTA 须回脚本审批，标题卡不能替代完整口播。
- 补充截图/SHA/时间点冲突处理，以及正负触发、授权冲突与只读会话回归场景；区分会话内验证和新上下文自动触发证明。

## 2.2.0 - 2026-10-10

- 区分完整口播字幕（`verbatim_voiceover`）与参考片卖点压缩字幕（`editorial_keywords`），要求脚本合同明确字幕内容模式与交付方式。
- 明确用户要求完整口播上屏时不得以场景标签代替；按最终成片口播时间轴排时，并增加逐句覆盖与可开关字幕轨验收。
- 修正字幕规范、后期验收矩阵、图文示例与 P007 模式，避免把参考片视觉风格误解为字幕内容范围。

## 2.1.0 - 2026-10-08

- 根据两条本地竖屏参考片的抽帧观察，补充正文字幕格式：单行居中、白字粗黑描边、1–2处事实锚点标黄、无底框；标题卡分开排版。
- 新增 `references/subtitle-style.md`，记录位置/字高建议、文案压缩、关键词高亮、字体与视觉 QC 拒收条件。
- 新增 P007 原始观测记录和图文笔记示意图；公开仓库不包含参考视频或真实视频帧。

## 2.0.0 - 2026-10-08

仓库重建，目录重组为 skills / wiki / raw 三层。

- 重写 `SKILL.md`：领域锚点前置的触发描述、两种模式对照表、细节下沉到 `references/`。
- 新增 `PURPOSE.md`：说明 Skill 存在理由与对应 wiki 模式。
- 新增 `references/trigger-design.md`：触发机制设计与正负向样例。
- 新增 `references/overall-plan.md`：整体方案冻结细则从 SKILL.md 下沉。
- 新增 `references/examples/`：图文笔记示例（示意图 + 判据），不含视频/音频素材。
- 移除对已并入的 `shooting-plan-freeze` 的引用。
- wiki 层新增 6 条模式，raw 层新增 2 条不可变执行留痕。
