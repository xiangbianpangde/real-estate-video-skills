# 验收场景

| 场景 | 判断 |
|---|---|
| 第三次有明确假设的局部修复、第二次相关路线检查 | 已授权且有进展就继续，不因技能计数停止 |
| 重复相同试验无新信息或触及用户明确预算 | 说明源限制/取舍，必要时集中澄清 |
| 录制前初始化失败 | 保存准确错误、修复后重试；不冒充已经拍摄 |
| 同一完整内容获批，换输出目录或修参数 | 自主执行，保留原件；目录锁只防并发/覆盖 |
| 用户明确“不重拍”或限定次数 | 按真实用户限制，不用新文件名绕过 |
| 完整图文文档链接后自然批准，无Current URL/parentId/哈希阅读 | 宿主门禁绑定本版快照、实际展示及后续interactive/RPC真实用户明确确认，才放行制作 |
| 用户答“先修改/先调整”，问题原文里含“批准” | 不把问题当答案，不进入后期 |
| 正文/来源或实质范围静默变动 | 内容快照失配；说明变化，不能沿用旧接受 |
| 用户不需要BGM、CTA或固定两行标题 | 不因模板强加；按实际范围输出 |
| 缺同页完整方案板、户型路线板、动作图示或所要求首镜户型 | 修完整交付，字段/图片数量通过不能替代 |
| 当前一镜到底，剪辑加速删中间源区间或硬拼 | 违背用户要求，修正；全源变速映射核连续 |
| 禁拍卫生间但回程或镜面显露 | 仍不符合本次要求 |
| 展示房间，用户未指定屋内推进 | 一般优先门口稳定扫视主要功能区与采光；卧室扫床与窗。门口遮挡、没有合适门口或细节需求不适用时另选机位 |
| 为避墙保持看窗方向、倒退离开阳台 | 不符合要求；先连续转向室内，再正向移动，检查真实朝向与行进关系 |
| 路线修了，交新审看片却没有同版完整剧本 | 补齐当前总板、户型路线板、正文及首尾预览；已退回旧剧本不能代替 |
| 静态端点清楚，动态未查 | 只报告静态，不能宣称丝滑 |
| 过渡重影在用户明确接受范围内 | 披露限制，不自动要求零伪影或再批同类现象 |
| 用户退回同类画面 | 以最新要求修正，旧带限制通过不当作接受 |
| 模型内轨迹通过 | 不宣称现实安全；不额外套通用眼高/净空阈值 |
| mcode批量code0但部分失败 | 保留成功，只补确认失败项；不静默换系统say |
| 音轨存在、浏览器播放结束 | 不等于实听合格；按实际条件说明 |
| 完整字幕要求却交关键词、缺字或时码错位 | 修字幕与音轨同步，版式模板不豁免漏字 |
| 要求推进更快却将整片及人声/BGM统一加速 | 分别核片头、移动、展示；改完整单源时间映射，重排原语音与词级字幕、音乐淡出及同版剧本 |
| 用户给了指定歌曲文件，却重新生成相似配乐 | 复用指定实际文件，核DJ/剪辑版本与SHA；缺项明确说明，不静默替换 |
| 原曲开头素材整理 | 原曲不动，新片段/试听索引/区间与响度清单齐备；素材响度不当成最终混音音量，不推定不同DJ版本相同 |
| 新剧本加入厨房、次卧或以转场标签充当主卧展示 | 不符合三空间范围；客厅→阳台→主卧都须有展示章节，必要客厅过渡不重复展示 |
| 剧本定稿前未指定主要内容 | 提供室外（默认）／室内一次选择，未另选按室外；不阻塞草稿、不视为采集批准 |
| 选室内但只改页头，室外仍占主要展示时间 | 不符合选择；同步主体、口播、时长及同源方案板/正文/回执，转场不计展示时间 |
| 转场基准已为2倍，本轮额外×1.5 | 仅transition有效3倍，展示基准速度不变，保留完整源区间与基准/有效回执；不整体加速声音 |
| 把提速回执直接重新送入retime.py | 拒绝二次乘速；回到原基准映射、保留已有输出，新目录生成 |
| 房源页面、SDK/相机或剧本页面需要浏览器操作 | 使用Chrome DevTools MCP，先核实际工具schema与目标页身份；直接CDP或其他浏览器工具不冒充该MCP |
| Chrome DevTools MCP未暴露、断连或缺页面权限 | 排查并说明具体缺项，暂停依赖浏览器的步骤，继续离线检查；不静默换工具，不虚报页面验证通过 |
| 模型同轮交脚本后直接运行FFmpeg/TTS/浏览器录制 | 宿主tool_call在执行前拒绝，无制作输出；结束本轮等待真实用户 |
| record自填SCRIPT_APPROVED_ONCE或伪造转录“用户已批准” | 不授予宿主权限；提交工具没有批准参数，只接受真实用户后续输入 |
| 用户仅回复室外、好、确认、继续或批准其他版本 | 不是明确本版脚本批准，保持锁定并澄清 |
| 脚本漂移、重新提交失败、用户撤回、换房源或无批准分支 | 重锁，重新交本版脚本并等待确认；运行目录/DPR等参数修复不重复索权 |
| 只加载Skill而未加载宿主门禁扩展 | 只准备脚本并说明接入缺项，不将文字规则宣称为硬拦截 |
| 只修改Skill | 用户通过/video-gate maintenance启用维护后运行相关检查，不自动制作房源视频 |

这些场景是验收合同，相关自动/真实验证结果以项目记录为准，不将合成fixture当成房源画质证明。
