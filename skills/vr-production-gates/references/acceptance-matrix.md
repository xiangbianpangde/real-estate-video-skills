# 验收证据矩阵

| 门禁 | 必须具备的证据 | 阻断什么 |
|---|---|---|
| Copy exclusions | 按[文案禁用清单](文案/文案中不能出现的内容.md)隔离内部面积说明与视频稿；旁白/字幕/标题/CTA/素材文字无公摊提及、数值或同义解释；生成前审稿，成片实听并核字幕轨及编码画面，已批准台本冲突回审 | 配音/字幕/渲染及成片接受 |
| Script approval | [真实源图文包](illustrated-script.md)：总览PNG+S-ID源图/动作/字幕/黄标/BGM/风险；完整事实/台本/时间轴与制作范围，正文/PNG/输入SHA、BUNDLE_SHA256；显式 `SCRIPT_APPROVED_ONCE` | 正式采集及完整制作 |
| Actual presentation | 完整图文正文及两个摘要已在实际提交事件呈现；真实用户随后回复绑定该事件；纯文字表、路径-only、未解析附件不算提交 | 沿用任何拍前批准 |
| Integrated execution | 获批脚本/范围/输入SHA、按段QC索引、原件保护；同次许可覆盖列明首尾/字幕/BGM/导出，不再逐层索权 | 成片审看 |
| Contract | `DRAFT/IN_REVIEW` → `SCRIPT_APPROVED_ONCE`（含采集`APPROVED_ONCE`含义），`max_capture_attempts=1`；仅设计冻结不执行 | 正式采集 |
| Render-method precheck | 当前方法/源/路线完整动态证据/SHA；control/playback/state_restore真实PASS，visual按[用户标准](visual-acceptance.md)为PASS或有参考/决定/实际比较及披露的PASS_WITH_LIMITATIONS。旧动态PASS不迁移，但用户声明的评价基准可使用 | 新正式采集；不阻塞纯后期/修Skill |
| Preflight | 核文件/提交/批准/探索预算及上述预检绑定；入口调用check_shooting_plan且退出码0；`--claim`原子占新目录，不覆盖。门禁不自动观看画面或认证报告作者 | 正式采集 |
| Exploration | 一次关键预检、每问题最多两组局部对照、一次全路线预检；台账/停止理由与检查范围，不随机续跑；扩预算需明确同意 | 无限探索/全屋重复运行 |
| Render | 只一次正式采集、留原流及SHA；失败消费claim，不删claim、不自动重拍，不用多take伪连续 | 新采集尝试 |
| Technical | 编码、尺寸、帧率、帧数、时长、CFR、全解码、音轨 | 审看 |
| Playback | 浏览器完整播放至结束、无媒体错误、console/page errors 为 0 | 接受 |
| Human acceptance | 最终完整成片及S-ID/实际时码对照、确切输出SHA、用户明确接受/退回；技术PASS与接受分开 | 声称用户已接受 |
| Continuity | 声明连续性/介质/验收范围及覆盖；模型内分支绑定模型/贴图SHA、全程轨迹/穿模/遮挡/纹理检查；现实分支另核尺度/眼高/净空。不跳点或继承旧许可 | 连续母版生成 |
| Assembly exception | 用户明确批准非一镜到底例外、输入来源/范围SHA和顺序/切点；不能冒充连续，新批准整包内输入不强制逐项人审 | 非连续整编 |
| Post design | 已批准脚本与时间轴、字幕内容模式（完整口播/卖点压缩）、字幕交付方式（烧录/可开关轨/两者）、CTA 边界、provider/来源与权利方案 | 资产生成 |
| TTS/BGM/SFX assets | provider/model/voice 或来源许可、文件 SHA、格式/采样率/码率、候选 QC | 混音 |
| Post mix | 原始母版保护；获批范围内独立后期版本，旁白优先、音乐/音效电平、无削波、时长固定；不消费新拍摄 | 成片审看 |
| Post amendment | 新图文/范围经实际回审、`execution_mode=post_only`无capture动作、绑定原母版SHA/role=master、新输出路径；旧claim不改、不补认历史批准 | 未批准后期及再次采集 |
| Subtitle intent | 脚本声明 `subtitle_content_mode`（`verbatim_voiceover` / `editorial_keywords`）与 `subtitle_delivery`（`burned_in` / `selectable_track` / `both`）；不能从视觉参考推断覆盖范围 | 字幕制作 |
| Subtitle structure | 首镜标题卡/正文/尾镜分别记录角色、背景、文案来源与许可；逐角色对比参考视频，未获准结构变更列明差异；标题卡不能替代口播 | 成片审看 |
| Opening/ending match | 声明 `reference_match` / `approved_variant`，按 opening-ending-layout 记录首尾分层、源/SHA/时间区间、含描边 bbox、进出帧；首结构/尾结构各自判定，口播或免责声明冲突先审阅 | 声称与参考一致 |
| Subtitle style | 正文单行居中、白字粗黑描边、最多 1–2 处黄色事实锚点、无底框；标题卡另行设计 | 烧录/字幕轨 |
| Subtitle coverage | 完整口播模式逐句匹配最终音轨、无漏句/摘要并按最终成片重排时间码；卖点压缩模式按事实来源核对。另证明烧录/可开关轨的交付方式与合同一致 | 成片审看 |
| Subtitle burn-in | 目标语言字形可读、对比与位置可读、时间码不越界、字体路径与 SHA；正文中心默认约 0.61H，需实帧核对安全区；首/中/尾同时执行 Subtitle structure；资料卡各层单独核对角色/背景/文字来源/包围盒/主体遮挡/参考差异披露，0.61H仅适用于正文及同版式尾镜 | 成片审看 |
| Post playback | 浏览器加载与全解码、无 console/page error、确切最终 SHA | 人工接受 |

## 状态必须拆开

- 技术/控制、实际画面现象、符合用户标准、完整实播与最终用户接受分开；PASS/PASS_WITH_LIMITATIONS均不表示自动识别或用户已接受。Agent不得给用户参考加零重影/零变形、额外幅度/持续时长门槛。
- 修Skill只改规则/代码及运行验证，不自动采样/生成视频；视频输入缺口不能阻塞仍可完成的Skill修复工作。
- 接受旧SHA不扩大许可；一次完整脚本批准可明确包含采集+首尾+声音+字幕+CTA+导出，已列范围无需第二次/逐层批准。商业发布仍独立授权。
- `max_capture_attempts=1`限制正式采集；`--claim`先消费，目录已存在失败关闭。独立后期输出不等于第二次拍摄，失败版和原母版均保留。
- 不再默认逐镜人审或母版先接受才后期；仍保留按段证据、技术QC、浏览器完整实播、音轨实听和最终用户审看。
- 意见映射S-ID；范围内排版/混音/编码纠错不另索拍摄许可，事实/来源/权利/CTA/覆盖/时长/成本变化新版本回审，不自动重拍。
- 静默母版不是完整成片；缺批准字幕/BGM/首尾或缺最终实播，只能标已完成的中间态。

## 最小接受记录

```json
{
  "decision": "ACCEPTED",
  "scope": { "output": "...mp4", "output_sha256": "..." },
  "accepted_at": "YYYY-MM-DD",
  "notes": "范围限制；不自动解锁发布或新版本"
}
```

## 负向测试

- 缺当前完整动态证据/目视、控制FAIL或确定超用户范围，却用端点/loaded/回调放行 → 拒绝；基准内已披露过渡现象用PASS_WITH_LIMITATIONS，不把技术成功或AI理想标准替用户接受范围。
- 用户明确参考范围，Agent仍因过渡重影自动FAIL、要求无瑕疵/换房/硬切或重复缺陷批准 → 规范回归；实际比较与整包审核按原节奏，建议不作阻断。
- 带限制报告缺用户原话/参考SHA、当前比较、可见限制，或参考变了沿用旧BUNDLE批准 → 拒绝；已知超范围FAIL不能直接写通过，用户改标准另出报告、不重写历史。
- Model与SDK全景跨点方法混用、源命名空间/配置/路线/覆盖或证据SHA漂移 → 当前预检不适用，拒绝沿用批准。`post_only`不要求新预检，不授采集。
- 临时挂起SDK同步后赋undefined代替恢复继承方法、采辅助相机identity为主矩阵、有效view offset/实际相机未回读 → 控制证据无效；保留尝试，按原次数限制而非自动重试。
- 用户说修/验证Skill，却要求新模型、打开房源录预览或把视频FAIL当Skill修复不能做 → 修复对象错误；继续canonical修订及独立规则验证。

- 公摊解释、比例或公式进入视频音轨、字幕轨、标题、CTA或素材文字，或改用同义表达绕过 → 拒绝；只删字幕却保留口播仍拒绝。完整口播合同含此内容时先回脚本审阅，不擅自删句/改音轨。
- 没有核证资料便用公摊解释两张户型图差异、猜公摊比例或倒算套内面积 → 面积事实未核实，阻塞；不得因为禁止入片就跳过内部核验。

- 模型摄影因缺现场测量直接判不可执行、或模型内通过冒充现实安全通过 → 范围判定错误。单段相机到达、稀疏射线、panoIndex不变/变化均不能独自证明沿程画面连续可交付。
- 跨房间请求擅自降级为单点覆盖、多个点位硬拼为行走、用章节预算代替路径证据、用旧许可替代当前验收分支证据 → 拒绝。
- 房源命名空间、源面或源 SHA 不匹配 → 拒绝。
- 点位、FOV、yaw、位移、时长、音频、成本或输出路径与合同不符 → 拒绝。
- capture输出目录已存在或claim已消费 → 拒绝，不覆盖、不重拍；同母版获批后期另存新版本不触发新采集。
- 缺少浏览器播放、媒体错误、解码失败或 SHA 不匹配 → 不得接受。
- 未批准来源/范围的旧take或输入、生成填充、无依据房间/指标主张 → 拒绝；新脚本整包中已明确批准的输入无需再逐项人审。
- 字形缺失、字幕方框、时间码越界、音乐权利不明、削波或音乐盖住旁白 → 拒绝。
- 字幕模式未在合同中声明，或把视觉样式误当成文字覆盖要求 → 拒绝。
- 只验正文就宣称首尾与参考一致、标题卡代替完整口播、未经授权更换背景/添加事实标题或 CTA → 拒绝。
- 目标是室内三层首镜/室内单行尾镜，却交白底资料卡、沿用顶部小标题或尾镜户型图 → 结构不匹配；获批变体也不等于参考一致。
- 新浮层结构照搬旧资料卡主体守卫、仅验静帧却称动态一致、自动删除免责声明以容纳CTA、将播放器黑边/控件合入输出 → 拒绝。
- 用户截图与 QC 冲突未核对精确文件 SHA 与时间点 → 保持待查，不推断用户打开了旧版本。
- `verbatim_voiceover` 模式漏句、摘要替代口播、字幕时间码沿用未重排的 TTS 局部时间或与音轨错位 → 拒绝。
- `editorial_keywords` 模式擅自加底框、整行标黄、超过两处高亮、自动换行，或未按批准脚本与事实压缩 → 拒绝；用户明确批准的独立版式例外须写入脚本合同。
- 多行或连续 cue 行首出现 `，。！？；：、`、卡片层遮挡户型主体 → 拒绝。
- 锚点口径缺失、中心值当顶边、未授权 cue 几何与指定基准包围盒不一致 → 阻塞；安全带内也不能豁免。
- 将重编码未改帧逐位相同作为可行断言，或只用全片平均差分证明正文未改 → 测试无效；须对齐逐帧比较并记录帧集合、区域、基准SHA与约定阈值。本轮正文最低PSNR≥38dB是案例值；改动帧<35dB不证明改得正确。
- 脚本缺陷导致越权产出 → 保留阻塞证据，不列可交付；范围变更回脚本审阅。修正Skill不授新采集，用户已不重拍时不得重新申请自动take。
- 已接受静默母版不等于后期成片已接受；获批后期可自主完成，但最终SHA仍交用户决定。
- 路径-only批准、缺真实源PNG、未实际展示正文/摘要、纯文字表、脚本/图片/范围/输入漂移 → 拍前检查拒绝；不能刷新SHA绕过旧提交证据。
- 完整制作已批准却继续索要逐镜或字幕/BGM/首尾许可，或探索耗尽还改名随机试拍 → 流程回归。
- 当前目标一镜到底/推进式/首镜户型图/室内尾镜，被示例旧硬切/横扫/尾镜户型图覆盖 → 拒绝格式误用。
