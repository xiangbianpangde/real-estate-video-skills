# 图文拍摄脚本模板 · vN

> 复制到私有项目的新版本后填写；本模板不是可批准房源脚本。所有 `待填` 必须解决，图片必须替换为本房源真实源PNG，不把公开示意图当取证。审批后不要改写原文件。

## 先生成可审方案板

按[方案板版式合同](storyboard-layout.md)生成overview.png。顶部整片目标/章节顺序；中部横向S-ID卡片，每卡直接排入真实图、时间、动作图示＋短说明、重点、口播/字幕、黄标和限制；下部真实户型、调整说明和待审核范围。参考图的排版保留，房源、章节数、拍法与审核节奏按当前任务重建。截图下另写字段只是附文，不能代替成图。先渲染、目视核对，再填写v3的版式回读证据。

## 整体方案

待填：覆盖/顺序、一次正式拍摄、模型/现实验收分支、当前源与成像方法/配置、动态预检结论/适用区间、路线、约定时长/容差、已知源限制、图文版本。旧全景/旧方法PASS不能当当前方法证据。

把私有 `overview.png` 用Markdown图片语法放在本标题下，alt写明“整体路线、覆盖与首尾方案”。此模板仅说明格式，不嵌不存在的占位图。

复制到私有项目后必须替换成图片语法与实际文件；本模板自身不能通过生产检查。

## S01 · 首镜

画出真实室内背景＋真实户型浮层＋两行标题的布局预览，标明非已录成片；保留源图取证索引。不能只放未经合成的室内截图。填写visual.title=户型开场、layout=opening_composite、两行headline_lines及motion图示类型/短标签。

把本房源 `S01.png` 嵌在本标题下并注明来源及SHA。需要户型图开场时，列出原户型图SHA、室内连续背景、标题/户型浮层及退出时间，不能改成尾镜户型图。

图片alt写明“S01 首镜真实源参考”，链接使用相对路径；本模板不含真实图。

| 字段 | 可审内容 |
|---|---|
| 时间 | 待填：0.0–N秒；连续镜头，不是切点 |
| 动作/重点 | 待填：推进动作、观看关系、主体；不能只写“展示房间” |
| 字幕/黄标 | 待填：原文、黄标词、事实来源；白黄粗黑描边 |
| 音乐/口播 | 待填：素材库来源与授权池、音乐方向、是否无口播；有口播附全文 |
| 风险/证据 | 待填：已披露伪影、穿模/遮挡与连接检查、源PNG/SHA |

## SNN · 室内收尾

把实际收尾室内真实源PNG嵌在标题下。注明末段动作、CTA原文/黄标/许可、音频尾音及最后有效帧；不照搬示例房源名或改变完整免责声明。

## 制作与验收范围

- `capture_medium` / `render_method` / `validation_scope` / `continuity_class`：待填；同点全景、Model、SDK全景跨点不能混用。
- `source_namespace` / `render_config` / `render_validation`：待填；列当前动态证据/范围/限制并绑定SHA，缺证据或未决/超范围FAIL不采集。
- `visual_acceptance`：有用户参考时列文件/SHA/决定原话，按[视觉标准](visual-acceptance.md)比较、披露；没有参考则删除记录模板中本对象和两项acceptance assets，不额外索参考批准。PASS/PASS_WITH_LIMITATIONS按实际用户标准，不自设零伪影/时长/幅度上限或把基准内表现列为必修。
- `max_capture_attempts=1`；原始录制及独立后期输出路径：待填。
- 字幕 `subtitle_content_mode` / `subtitle_delivery`：待填。
- 授权动作：一次采集、首尾包装、字幕、BGM、编码/QC；有配音/音效需逐项列明。获批后无需逐层申请。
- 事实与权利来源、素材库BGM授权池、付费上限/零新增付费：待填。
- 未授权：商业发布、未列付费、新事实/CTA、第二次拍摄。
- 探索证据：一次关键预检、每问题最多两组对照、一次全路线预检的实际次数和停止理由。
- QC：技术/控制、实际视觉现象、是否符合用户标准、字幕/音频和完整实播分开；最终SHA交用户决定，预检带限制通过不代签最终接受。

## 提交与批准

拍前先生成正文/图片/输入/范围SHA；在实际消息中呈现完整图文脚本及摘要。保存该事件ID与用户随后的明确决定。文件路径-only、模板未填写或旧DRAFT中的其他路线不算可批准对象。用户批准后仅生成一次正式take；本模板不产生任何许可。

批量记录结构、检查命令与限制见 [图文脚本协议](illustrated-script.md)。
