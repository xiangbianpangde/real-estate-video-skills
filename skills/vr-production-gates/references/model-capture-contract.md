# 模型摄影

使用当前房源已采集的模型和贴图，记录Work/素材身份及文件SHA。模型渲染不等于真人现场行走，模型里的尺寸或轨迹不自动构成现实安全认证。

scope声明capture_medium=model_render、render_method=model_mesh、validation_scope=model_only，以及实际配置、路线、覆盖和render_validation；资源列入assets.role=source。字段规则见[连续技术](continuous-take.md)。

检查明显穿模、跳变、主体遮挡、缺面与纹理畸变，并按当前用户要求决定可用性。不要把所有现象都归为源缺面，也不追求无依据的零伪影。相关片段验证可以自主重试，没有固定次数配额；重复无新增信息时报告能力上限。

同模型内纠错与改参数通常属于已授权实现。换来源、改变对外表达/覆盖或新增费用时对齐；修Skill不自动运行模型或制作视频。
