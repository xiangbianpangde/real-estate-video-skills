# 触发与验证

房产视频的图文剧本、VR/模型拍摄、配音字幕、成片检查或本技能修订使用本技能。普通房源搜索、购房政策、通用非房产剪辑不由它接管。description是触发入口，metadata.triggers仅作索引。

| 输入 | 预期 |
|---|---|
| 用真实房源先画完整剧本，审核后制作 | 使用，交完整内容并一次核范围 |
| 修复房产视频Skill的次数配额，不拍视频 | 使用，改规则/执行检查，只验证Skill |
| 原视频停顿，保留一镜到底并压缩等待 | 使用，核实际源区间与连续变速，不套固定尝试次数 |
| 给房产片用mcode配音并完整字幕上屏 | 使用，按指定声音链路与最终音轨对齐 |
| 用户接受完整内容，说“接受，现在开始” | 按实际会话对象记录批准，不另索哈希/口令 |
| 查两百万内三房 | 不使用，交房源检索 |
| 婚礼视频转码 | 不使用，交通用媒体工具 |

规则/CLI回归、Pi loader与新上下文真实模型触发是不同证据。只运行本次相关检查；未进行真实模型触发时明确未验证，不虚报。维护Skill不因未来场景全集尚未测试而停止交付。
