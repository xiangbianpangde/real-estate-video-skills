# 用户明确排除的文案内容

文案限制来自本次用户指令和已批准内容，不把某一房源的要求写成行业禁令或其他项目默认值。具体房源限制由调用方的项目记录维护；用户后续明确修改时以新指令为准。

例如用户要求“视频不解释公摊”时，旁白、字幕、标题及素材内嵌文字都应符合该要求，而不是只删字幕。内部面积核验仍可区分建筑/套内/使用面积口径；没有资料时不猜比例或用不同口径面积求和冒充同一指标。

发现稿件与本次限制冲突时，在已授权范围内直接修稿；涉及已批准事实/台本的实质变化时说明影响。不为关键词扫描另设逐句授权或音视频审批层。检查实际输出，并将具体限制及来源留在项目事实记录，避免依赖通用Skill中的旧项目状态。
