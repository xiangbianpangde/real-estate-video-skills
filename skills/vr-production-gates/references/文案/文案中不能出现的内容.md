# 文案中不能出现的内容

本文件是房产视频文案的禁用内容清单。写作、审稿、TTS/字幕生成前及成片验收时必须读取。当前只登记用户明确要求的公摊相关禁用项；不自行扩充名单。

## 01 · 公摊相关内容（内部可解释，视频禁止出现）

> 口径提醒：公摊口径可能导致内部计算面积与房源说明面积不一致；该差异只用于内部核验，不得向观众提出“公摊面积”或任何相关解释，避免产生消极影响。

### 内部用途

- 面积核验与计算解释须考虑公摊口径，区分建筑面积、套内建筑面积、套内使用面积及各房间标注面积；不得将不同口径直接比较或求和后冒充同一指标。
- 在适用且有资料支持的同一测算口径下，可用“建筑面积 = 套内建筑面积 + 分摊的共有建筑面积”解释计算关系。套内建筑面积不等于套内使用面积，各房间使用面积之和也不能直接当作套内建筑面积。
- 公摊仅可写入内部面积核验记录或向用户解释面积计算的非视频说明，标明来源、计算口径、已知项和未核实项；不得混入待配音或待上屏稿件，也不得包装成面向观众的面积差异解释。
- 不猜公摊比例，不倒算未经核证的套内面积，不把两张户型图的面积差异直接归因为公摊。用户说明“考虑公摊”不是具体比例或面积数值已核实的证据；差异仍须核对图纸来源、版本和面积口径。

### 视频禁用范围

以下内容不得进入视频口播、TTS、字幕（烧录或可开关字幕轨）、首尾标题、CTA、画面说明、户型图文字或其他可见/可听层：

- “公摊”“公摊面积”“公摊比例”“公摊率”的提及、数值及计算说明。
- 换成“分摊的共有建筑面积”“共有部分分摊”等同义表达，或用公式、图解、旁注、免责声明变相说明公摊。
- 为解释面积不一致而添加的公摊推断，例如“面积差是因为公摊”“扣除公摊后实际为……”。这些是反例，不可复制到视频稿。

仅避免某个词不够：须检查语义，确保视频不以替代表达讲述公摊。建筑面积等已核实且获准的面积事实并非一概禁用，但不能借其展开公摊解释或引入未经核证的换算结果。

### 制作与审稿门禁

1. 内部面积核验记录与视频文案分开保存。视频稿只选已核实、口径明确且获准的面积事实；事实核验与允许入片是两道独立门禁。
2. 生成声音或视频前，检查旁白、字幕、标题、CTA和画面素材内嵌文字。发现公摊内容则阻塞，先修稿或选取无禁用内容且获准的素材；不能只删字幕却保留相应口播。
3. 已批准台本或素材含公摊内容时，报告与本规则的冲突并回脚本审阅。不能以“完整口播覆盖”或“保留原图”为由豁免，也不能擅自改音轨、删句、遮盖或重制素材；规则更新本身不授予生产许可。
4. 成片逐段核对实际音轨、字幕轨及编码画面（含户型图小字）。关键词扫描仅辅助检查，不能替代同义表达审查、实听和实帧核验。任何可见或可听公摊解释均拒收。

## 规则回归场景

| 场景 | 应有处理 |
|---|---|
| 用户询问为何面积计算不一致 | 非视频说明中可以解释公摊口径，明确未核实边界，不擅自确定差异原因 |
| 视频展示已核实并获准的建筑面积，不解释公摊 | 本条不阻塞；仍执行事实与授权门禁 |
| 旁白无“公摊”字样，但讲“共有部分分摊比例” | 按语义拒绝，不能用同义词绕过 |
| 户型图小字含公摊，字幕与口播均未提及 | 仍阻塞，图片文字也属于视频内容 |
| 已批准完整口播包含公摊解释 | 回脚本审阅，不单删字幕、不自动重配音 |

回归场景是预期行为说明，不代表已生成或验收新视频。
