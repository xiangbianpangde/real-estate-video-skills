# 首尾预览与成片

用户要求参考对齐时，先提取结构、信息层次与动态关系，用当前房源素材实现；参考的名称、面积、图片和承诺不继承。

当本次要求首镜为室内连续背景＋保比例户型浮层＋标题，或尾镜为室内收束/留言时，图文剧本实际画出所要求的层，不能只贴室内截图。标题行数、字号、圆角与位置按内容可读性决定，原“两行”等只作模板；无引流要求时允许仅收束或声明。

核户型不拉伸、不截断必要信息，标题/口播不互相遮挡，浮层退出与原片自然衔接，首尾无黑帧/残留层。阅读时间、真实源画面与音频尾音一起检查。

常规布局、角度和编码修正在已授权范围内自主进行；改变事实/承诺、用户明确要求的结构或来源权利时才对齐。无需单独的首/尾许可、每层bbox或字体SHA表。

检查首镜、退出、尾镜与最终播放；结论说明结构是否对应、文字是否完整、实际动态是否检查，不能用正文检查或平均PSNR代替首尾观看。像素复刻仅在用户明确要求时另设测量目标。
