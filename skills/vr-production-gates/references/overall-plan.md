# 整体方案与完整制作批准

整体方案解决“整片怎么拍”。默认将它与图文脚本、制作范围合成一次拍前审核；只批准整体设计与批准完整制作必须明确区分，不能保留两套默认审批节奏。

## 版本化

每版新文件/目录，不覆盖历史方案、已登记PNG、原始资产、冻结合同、take或审阅。标题/文件名/正文/PNG同版，写变更清单；执行对象不能继续名为旧`v3f_DRAFT`而内容悄悄换成v3g。PNG相对路径嵌入对应Markdown，HTML/SVG只作图源。

## 一次审阅的内容

1. 覆盖空间、观看顺序、完整候选路线与连续性分类；章节不是切点。
2. 总时长及容差、章节时间轴、推进/转向动作与画面重点。
3. 真实源图文卡片、源/模型/贴图身份SHA、事实/权利、风险与有限探索证据。
4. 首镜户型图/室内连续背景、尾镜室内收束/获准CTA、白黄字幕的覆盖/交付模式。
5. 素材库BGM授权池、音频方案、付费上限、导出/QC范围及一次正式采集。

详细卡片与实际展示规范见 [图文脚本](illustrated-script.md)。图中箭头不是现场测绘；模型内路线不声称真人安全。同一模型内检查轨迹/穿模/遮挡/纹理；只有`physical_verified`另要现实尺度、眼高/净空证据。模型分支不能因缺现场测量自动阻塞。

## 方法候选池

每项记录方法ID、类型（真实采集/后期/叙事）、证据状态、原房源、当前房源适用性、取证缺项。候选/静态参考或第一房源实测配方都不自动跨房源解锁；风险集中澄清，不自动切逐镜。硬切仅限明确获准非连续例外，不称一镜到底。

## 状态与许可范围

| 状态 | 含义 |
|---|---|
| `DRAFT` | 编写/未填写完，不可生产 |
| `IN_REVIEW` | 已实际交付可审图文内容，等待决定 |
| `ACCEPTED_FROZEN` | 仅指定整体设计被接受/冻结，不授采集或后期 |
| `SCRIPT_APPROVED_ONCE` | 图文脚本及列明完整制作范围获明确批准，含一次正式采集与获准后期 |
| `SUPERSEDED` | 新版替代，历史保留，不沿用批准 |
| `BLOCKED` | 事实、权利、素材、关键证据或范围未决 |

一次明确批准可同时满足脚本和原`APPROVED_ONCE`采集许可，无需让用户念两种状态口令。批准绑定正文SHA、所有PNG/输入SHA、范围BUNDLE_SHA256和真实提交/回复事件，拍摄入口检查并消费一次claim。

**批准完整制作时**：在合同范围内自主录制、首尾、配音/字幕/BGM、混音、编码/QC，不等逐镜/母版/每层批准。**只批准设计时**：不得生产。旧接受与历史设计冻结不追认为新完整范围。

## 仍需回审及独立授权

新事实/CTA、覆盖/路线/拍法/时长、源/权利/付费/成本或范围变化须新版本并实际回审。未列付费、第二次拍摄与商业发布不自动授权。技术PASS、用户接受最终SHA、允许发布三者分开。

同一母版已批准范围内的字幕排版、混音和编码纠错可输出新后期版本，不消费新采集次数；原母版/失败版本不覆盖。用户明确不重拍时，不以回审或新文件名重启采集。批准记录形状见 [模板](freeze-record-template.json)，模板缺值默认失败。
