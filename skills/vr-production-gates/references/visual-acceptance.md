# 画面接受

用户决定评价目标，Agent记录当前画面的实际表现。参考片给出风格或质量依据，不自动继承旧房源的几何、事实、素材使用权或最终接受。

看完整相关区间，记主体/空间是否可读、停顿、墙面占比及投影伪影的具体位置。比较整体效果，不凭单帧重影自动拒绝，也不以帧率/加载成功证明丝滑。没有用户要求的零伪影标准就不自行增加。

PASS表示符合当前要求，PASS_WITH_LIMITATIONS表示可用但有已披露现象，PENDING表示尚未核实，FAIL表示明确违背要求。用户退回后以最新要求修正，旧带限制通过不继续充当接受依据。

不强制用户额外提供参考、写SHA或批准同类缺陷。已有参考时可在scope.visual_acceptance保留来源/决定；内部绑定与真实比较即可，不要求原话、路径和哈希全部出现在正文。没有参考时按用户当前要求评审并说明限制。

保留历史观察；标准变化不改变已经发生的事实，也不替用户接受新成片。已保存媒体足以判断时直接复用，不为修改评语重拍。
