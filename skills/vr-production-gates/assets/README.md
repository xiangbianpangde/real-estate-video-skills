# 可复用资产

本目录只放可复制使用的模板和设计资源，不维护具体房源状态、项目交接或本机素材位置。

| 资产 | 用途 |
|---|---|
| [templates/record.json](templates/record.json) | 新图文剧本的生产记录模板 |
| [design-system/tokens.json](design-system/tokens.json) | 默认颜色、字号和间距 |
| [design-system/styles.css](design-system/styles.css) | 方案板及组件样式 |
| [design-system/schema.json](design-system/schema.json) | record数据结构 |
| [design-system/examples](design-system/examples/README.md) | 合成源图、标准正反数据与已渲染示例；不是实际房源 |

设计规范见[设计系统说明](../references/design-system.md)，生成工具使用同一份record，不复制第二套组件。真实音乐、房源和制作输出由调用方指定素材根；是否随项目分发，按用户对该项目的实际授权处理。独立安装此Skill不要求存在原项目的materials或local目录。
