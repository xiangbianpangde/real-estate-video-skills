# 原始记录层（raw）

本层保存**不可变**的执行留痕：真实运行留下的事实记录，供 wiki 模式追溯来源。

## 规则

1. **只追加**：文件一旦写入不再修改。发现错误就新增更正文件，不改旧文件。
2. **只记事实**：记录当时的路径、SHA、命令、返回码和结论，不做解释性改写。
3. **脱敏**：公开仓库内不放房源 ID、经纬度、业主/经纪人身份、可识别的地址或联系方式。房源标识一律替换为 `HOUSE-REDACTED-NNN`。
4. **不放媒体**：视频与音频不进本仓库。公开仓库只保留图文笔记与示意图，媒体留在私有项目内并以 SHA 引用。

## 命名

```
R<YYYYMMDD>-<简短主题>.json
```

## 与 wiki 的关系

一条原始记录通常只支撑一条 wiki 模式。`wiki/patterns/P00X-*.md` 的"来源"字段应能追溯到本层的某个文件名。
